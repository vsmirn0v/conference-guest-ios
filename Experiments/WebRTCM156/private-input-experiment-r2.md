# Private input startup diagnostics r2

This experimental increment layers on [private-input r1](private-input-experiment-r1.md), with its same DEBUG/build/runtime gates and built-in/original-output-running restriction. It does not select a default backend, change normal VPIO/cache/publication gates, or add an output/VPIO fallback. The r1 candidate and its reproducibility files remain immutable.

[Patch](private-input-experiment-r2.patch) and [lock](private-input-experiment-r2.lock.json) bind all five preimages/final files to r1. Reconstruct r1 first, verify each baselineSHA256, apply with `patch --batch --forward --fuzz=0 -p1 --input <absolute-r2-patch>`, then verify final hashes. The independent reconstruction used zero fuzz; all referenced source files were checked for unexpected deltas. Build/test/package using the r1 recipe and locked arguments into a new root. Byte-identical rebuilding is not claimed. Required upstream/toolchain/r1 source inputs are not duplicated.

The explicit local root is `.build/audio-startup-followup/private-input-r2`, selected with `NativeMacGuest/build.py --framework-root`. Existing APIs and experimentalPrivateInput capability remain unchanged. All24 no-device tests passed, including retained diagnostic evidence after revoke, unchanged meter revocation, first-failure preservation and stale-token isolation.

`privateInputMeterState.startupDiagnostics` is passive numeric startup metadata, not PCM, level, meter authority or publication permission. It retains stage/failureStage/failureResult, native status/error identifiers, before/after bus/sink formats, route IDs and capture/generation counters, raw callback counts/times/shapes and final predicate mask after cleanup. Existing `meter` stays redacted after revoke. Callbacks and configuration notifications enter the drained owner gate before writing diagnostics; callbacks use bounded atomics only.

`nativeStartReturn`:0 not returned/not reached,1 returned false,2 returned true. `unitQueried` distinguishes an actual property query from default numeric zero. `nativeErrorDomain`:0 none,1 AVFoundationErrorDomain,2 NSOSStatusErrorDomain,3 other. `exceptionKind`:0 none,1 NSInvalidArgumentException,2 NSInternalInconsistencyException,3 NSGenericException,4 other; localized reasons/userInfo are not recorded. Signed codes are preserved. CLOCK_UPTIME_RAW timestamps match ProcessInfo.systemUptime.

`proofMask` bits0..12 are token-valid, unit-status-noErr, unit-running, engine-running, accepted-raw-callback, no-private-render, target-unbound, never-public-open, public-gate-closed, global-capture-closed, within-deadline, same-route and same-private-input-format. All thirteen must hold; no condition was relaxed. The first failed stage/result is retained separately from later teardown. A reported zero in the revoked public meter never proves that no callback ran; use retained diagnostic counters.

The Host38 r1 private start failed with kAudioEngineStateTransitionError and confirmed cleanup; logs did not distinguish an exception from a late proof rejection. This diagnostic build makes no fix/acceptance claim until a new bounded Mac pilot attributes the failure. Physical input-only capture, output continuity and subsequent cached first-network-unmute still need runtime proof. No Home capture or shipping pin update is included.
