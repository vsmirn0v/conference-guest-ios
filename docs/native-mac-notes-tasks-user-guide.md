# Notes, tasks and Obsidian on Mac

In **Assistant → Outcomes**, select a meeting to see its outcome and **My Notes**. Edit notes there or in the meeting’s notes panel; both use the same session document. Use **Formatted** or **Markdown** to change the editor presentation. The save indicator describes the local copy. If another window is editing the same note, use **Edit here** to take over.

Use the notes panel’s separate-window action to keep a meeting’s notes in their own window. Closing that window does not end the meeting. In Outcomes, use the rename action beside the meeting title to rename that session. Meetings are grouped by their effective day; older records may show an end-time fallback or an unknown date.

In **Assistant → My Tasks**, use **My names in tasks…** to confirm full owner names and aliases. Choose **All**, **Open**, or **Completed**. Complete or reopen a task with its checkbox. Archive a task from its row; use **Undo** immediately or **Manage archive…** to restore it later. Archiving does not change completion or erase historical meeting content.

In **Settings → Obsidian**, choose a vault and use the main integration switch plus **Save to vault after the meeting** and **Automatically sync changes**. Use **Format and placement…** to configure files, a worklog, or files plus an index. Delivery status is separate from local saving. If an export is paused by a setting, use **Send accumulated exports…** to choose which meetings to send. Resolve an external edit through the conflict review; a separate copy leaves the original conflict unresolved.

For a Runtime-style worklog with old day headings that omit the year, confirm the year for each identified section in the placement preview. The app asks again if a section’s identifying content changes. Earlier global-year settings require explicit confirmation of the individual sections.

Use **Export Markdown…** from a meeting or history to save independent Markdown without an Obsidian vault. On a local-save error, keep editing or use **Export draft…** to save the current in-memory text elsewhere. A draft export is not a successful local save.

These instructions describe the implementation under development. The [acceptance audit](native-mac-notes-tasks-acceptance-2026-11-11.md) records tested behavior and remaining verification before release.
