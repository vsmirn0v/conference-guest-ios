## Remaining substantive gaps and verification gates

The previously missing **v5→v6 archived-data fixture and historical MCP runtime contract fixture now pass**. The schema-v5-shaped upgrade fixture preserves task completion/archive, note IDs/revisions/text, binding/completion receipts and pending queue, and checks the pre-v6 backup. The historical MCP fixture exercises in-process JSON-RPC reads, archive filtering and scoped mutation using old IDs. Individual Runtime section-year mapping is now implemented and tested; the previous global-year limitation is removed.

1. **Signed sandbox and live lifecycle:** verify bookmark authorization after signed-app restart, unavailable/replaced vault recovery, last-editor/quit failure choices, detached notes with the main window minimized, and live call/device continuity. The hosted fixture exercised detached windows and session isolation.
2. **Remaining editing/display boundaries:** document undo, native paste, mode changes, marked composition, scroll anchoring and measured mixed-width table dividers pass. The 100 KiB bulk-paste sample reached offscreen raster in 388.18 ms. Physical screen paint, physical input-source composition, narrow-width table wrapping and accessibility remain unverified.
3. **Export controls and layouts:** Send accumulated presents dated meetings for individual selection and a preview of each queued snapshot. The release transaction rejects changed destination settings, changed snapshots and incomplete preview coverage; selected release is covered by a store fixture. Placement ordering and a deterministic external-write-before-replacement conflict are also covered; the complete placement/monthly/order UI matrix, other timing windows and all hybrid interruption points remain unverified.
4. **Task operations and latency:** completion, reopening and reassignment/add in a 300-session fixture took **10.99, 13.13 and 21.36 ms** from action through SQLite commit to the same data/filter projection used by My Tasks ([timing](/tmp/rock-notes-continuation-tests1.log:3252)). Verify screen painting, filter persistence, live model behavior and system notification cancellation/delivery separately. The export timing fixture does not establish final-end latency or sustained continuous editing under slow I/O.
5. **Migration/client boundaries:** the tested v5-shaped upgrade is substantive migration evidence, not a real user-library rollout or malformed-data rollback test. Historical MCP runtime behavior is now tested through the JSON-RPC server; a running UI-edit→external-client walkthrough remains unverified. Preserve originals and backups during any later deployment.

Current code includes date provenance, historical outcome snapshots, canonical tasks and links, shared notes/history, detached windows, immutable export intents, component recovery/completion receipts, metadata protection and conflict UI. The final tests support specific behaviors in the ledger; **127 passing tests and a signed build do not establish acceptance of all 41 scenarios, signed distribution, installation, or live-device operation**.
